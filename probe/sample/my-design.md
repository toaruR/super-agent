# 設計: コマンドラインでテキストを単語数カウントする小さなツールを作る

## 要求
- 引数で与えられたテキストファイル（または標準入力）の単語数を数え、結果を出力する CLI ツール `wc-lite` を作る。
- テストは pytest で充分（統合テスト・E2E は不要）。過剰な設計は避ける。

## 方針
- パッケージ `wclite` に `count_words(path_or_text)` と CLI エントリ `main(argv)` を用意。
- 受入は pytest のみ（mypy/ruff は今回は省略してトークンを抑える）。
- 依存パッケージなし（標準ライブラリのみ）。
