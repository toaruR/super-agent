## v4（指摘の設計還元 + 実装）— 89点 / 致命0件 → **合格**

**v3(92)→独立レビュー(unsound)→訂正(58)** を経て、指摘を設計に閉じ込めた。
H2/H3/H4 は設計のみでなく `verifiers.py` / `ledger.py` で**実装し、ユニットテストを通した**。

**v3→v4 の変更**:
1. **H4 解決**: 証拠に `tree_hash` を束縛（CVE の成果物束縛）。別パス複製でハッシュ一致を実測。→ C2 満点根拠
2. **H3 解決**: 台帳追記の原子性（1行=1 append / イベントID一意 / クラッシュ途中行棄却 / 単一Sequencer集中）。`ledger_test.py` で200並行イベントが順序・重複保持を確認。→ C4 満点根拠
3. **H2 解決**: `acceptance[].run` を `verb+args` 許可リスト化。`verifiers.py` で未知verbは実行前却下・`args`はシェル展開なし。インジェクション経路を封鎖。→ C2/C8
4. **C5 補完**: ベンダー内記憶の有効性をリースheartbeatに従属（失効検出）。→ C5 満点
5. **C6 補完**: 価格表を `config/prices.yaml` に外部化し週次fetch+人間承認ゲート。→ C6 満点
6. A-5/A-6/N=4/権限制御を設計・実測済みとして C1/C8 に反映
